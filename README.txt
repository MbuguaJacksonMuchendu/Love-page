ROMANTIC QR PAGE

Files:
- index.html: romantic webpage with photo, I LOVE YOU, and a YouTube player button
- her-photo.jpg: photo used on the page

The song player embeds the supplied YouTube video and requests playback from 00:22 to 00:45. The visitor must tap Play our song; browsers commonly block autoplay with sound. YouTube settings/availability can affect playback.

TO PUBLISH FOR A QR CODE (free GitHub Pages option):
1. Sign in or create an account at https://github.com
2. Create a new public repository, for example love-page
3. Upload BOTH index.html and her-photo.jpg to the repository's root (top level)
4. Open repository Settings -> Pages
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save
6. Wait for GitHub Pages to publish and copy the website URL it gives you (usually https://YOUR-USERNAME.github.io/love-page/)
7. Open that URL on a phone and test the Play our song button.
8. Create a QR code from the published URL using https://www.qrcode-monkey.com/ or https://www.qr-code-generator.com/; download the QR image and test it with your phone before printing.

Important: a QR code must point to the published website URL, not to a file on your computer. The page needs internet access for the embedded YouTube song.
